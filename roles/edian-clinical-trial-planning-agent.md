**Rate:** To agree

---

Build Edian's agent-assisted bid-package product for clinical-trial CROs end to end.

Help build the clinical trial planning agent, an agent-assisted product for clinical-trial contract research organizations. It turns a brief and source documents into a bid package: assumptions, feasibility, timeline, budget and proposal documents. The aim is a package a proposal manager can review and finish, with clear sources and consistent numbers.

You'll build the product end to end: a simple intake and bid thread, review tools for proposal and costing teams, document/data workflows, and dependable agent actions. Budget and timeline calculations run in deterministic code, with human review and sign-off.

The current app uses Next.js, React, TypeScript, Tailwind and Supabase, with Anthropic integrations and Vitest/Playwright tests. We're looking for strong full-stack delivery, care for useful interfaces, and experience making AI features reliable in real workflows.

Location: London-based; remote work is fine. Project length 2-6 weeks at 20-40 hours/week. Rate: to agree.
